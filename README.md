# Assistente de Gestão de Projetos — Vértice Tech

Este projeto foi desenvolvido como parte de um desafio prático da DIO, com o objetivo de criar um prompt estruturado para uso de Inteligência Artificial em um contexto realista de organização de projetos.

A proposta consiste em um assistente de IA voltado para a empresa acadêmica fictícia Vértice Tech, auxiliando na criação de tarefas, documentação, comunicação interna e acompanhamento de entregas.

## Objetivo

Criar um prompt capaz de transformar demandas da equipe em ações práticas para Jira, Confluence e WhatsApp, mantendo clareza, organização e padronização.

## Ferramentas relacionadas

- ChatGPT
- Jira
- Confluence
- GitHub
- WhatsApp

## Aplicações

O assistente pode ser utilizado para:

- criar tarefas no Jira;
- gerar documentação para o Confluence;
- organizar reuniões;
- registrar decisões;
- criar mensagens para a equipe;
- revisar entregas;
- padronizar o fluxo de trabalho da Vértice Tech.
